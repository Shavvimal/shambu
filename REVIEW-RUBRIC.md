# shambu review rubric

Each item has a test a reviewer can run. An item passes only when its test passes. Run from the repository root
(`src/shambu` is the package). "rg" = ripgrep.

## Architecture

1. **Front-end boundary.** Only `shambu/cli.py` reads argv or stdin, prompts or prints to stdout.
   Fail if `rg -n "sys\.argv|sys\.stdin|\bgetpass\b|\binput\(|\bprint\(" src/shambu --glob '!cli.py'` returns a line, or a library module imports `shambu.cli`.
2. **Dependency injection.** `Pipeline`, `Bambu`, `PrinterService` receive their adapters (`StudioCLI`, `PresetResolver`, `Placer`, `LimitChecker`, `Discovery`) in `__init__`; tests construct them with fakes.
   Fail if `subprocess.` appears outside `studio.py`, `printer.py` (arp, route, ifconfig) and `facade.py` (open), or `paho` is imported outside `printer.py`. Fail if `rg -n "subprocess|socket|npx|mcp" src/shambu/cad` matches (`tests/test_cad_cli.py::test_cad_package_stays_off_cad_programs`). `topo.service.Topo` receives its listener and its `LinearSolver` in `__init__` and only stores them; fail if `rg -n "subprocess|socket|paho" src/shambu/topo` matches.
3. **Constructors only store.** No `__init__` does I/O. (`StudioCLI.__post_init__` checks that the binary exists: that is a stat, documented.)
4. **Pure planning core.** `spec.py`, `assemble.py`, `layout.py`, `tower.py`, `edits.py`, `patches.py`, `recipes.py`, `printability.py`, `meshgeom.py`, `findings.py`, `integrity.py`, the CAD gate modules `cad/{spec,fits,linalg,solid,features,gauge,diff,judge,rules,run,report}.py` and the stdlib topology modules `topo/{spec,result,michell}.py` import no `subprocess`, `socket`, `paho`, `zipfile` (`integrity.py` reads entries through `threemf.Project`; `cad/load.py` is the CAD gates' file adapter).
   Fail if `rg -n "import (subprocess|socket|zipfile)|paho" src/shambu/{spec,assemble,layout,tower,edits,patches,recipes,printability,meshgeom,findings,integrity}.py src/shambu/cad/{spec,fits,linalg,solid,features,gauge,diff,judge,rules,run,report}.py src/shambu/topo/{spec,result,michell}.py` matches, or if `rg -n "^(import|from) (numpy|scipy|shapely|skimage)" src/shambu/topo/{__init__,spec,result,michell,service}.py` matches (these modules load the extras inside functions).
5. **Pattern economy.** Every Protocol or Strategy has two implementations or a test fake: `PresetSource` (DirectorySource, ChainedSource), `Placer` (ShelfPacker, BottomLeftPacker + test fake), `Footprint` (RasterFootprint, BoxFootprint), `SpreadProbe` (StudioProbe + test fake), `Rule` (Clearance, InsideBed, ExtruderReach, TpuOnMain, MeshSane, SequentialClearance, tower.TowerClear), `tower.TowerClearance` (FootprintClearance, BoxClearance + test fake), `Patch` (sixteen in `patches.py`, four in `edits.py`; the Protocol declares `touches`, `resolve_touches` and `verify`, and `PatchBase` gives their defaults, so no caller looks them up with `getattr`), `Discovery` (ArpProbe, SubnetProbe, SsdpListen), `CredentialSource` (OneShotCredentials, ProfileCredentials, StudioCredentials + test fake), `Vault` (FileVault, MemoryVault), `Listener` (CLI logger + test recorder), `PrintCheck` (MeshSound, Overhangs, Bridges, Thickness, Stability, Adhesion, BedFit), `cad.rules.CadRule` (CheckRule, FeatureRule, FitRule, ClearanceRule, SweepRule + test fake), `IntersectionEngine` (ManifoldBoolean, SampledContainment + test fake), `DistanceEngine` (ExactDistance, PrunedDistance), `topo.linsolve.LinearSolver` (SuperLUSolver, DenseSolver), the topology `Listener` (CLI logger + test recorder).
6. **Template Method is overridable.** A `Pipeline` subclass that overrides `export()` with a fake runs end to end in tests without Bambu Studio.

## Correctness

7. **CLI rules encoded, not remembered.** `CliCommand.args()` refuses a command with no action, orders `--no-check` before `--slice`, emits `--flag=0|1` for bools, joins `--export-3mf` to a bare name + `--outputdir`. Fail if a test for each rule is missing.
8. **Presets are complete.** `PresetResolver.for_cli("machine", "Bambu Lab X2D 0.4 nozzle")["machine_start_gcode"]` is longer than 10000 chars (the `include` templates are merged) and `check_compatible` passes for the X2D defaults.
9. **Assemble-list rules.** `assemble.validate()` flags: non-string `*_params` values, unknown keys, `pos_*` length mismatch, non-part subtype without `assemble_index`, height ranges on merged parts, > 36 plates, filament index > count.
10. **Placement is explicit and checked.** Every part has a computed bbox on the bed; `LimitChecker` flags overlap, bed exit, extruder 2 reach (x < 20.5 and the user's 235.5 limit) for the part's filament AND its height-range, sub-part and process support or interface filaments (one FAIL line per part and extruder), TPU off the main nozzle, non-manifold meshes.
11. **3MF integrity.** Each `Patch` declares `touches` (entry names or fnmatch patterns; none declared means `Metadata/*`), including the entries its slice invalidation removes or rewrites (`edits.SLICE_TOUCHES` plus `model_settings.config`). `Project.save()` compares every entry with the loaded bytes and raises, before writing, when an undeclared entry changed, was added or was removed, when a `3D/*` entry was added, removed or reordered, or when a `_rels` entry changed. Only the geometry edits in `edits.py` declare `3D/*` entries: the sub-model of the one object they name (resolved at apply time) and the item or component `transform` attributes of `3D/3dmodel.model`, rewritten by targeted text substitution. An edit verifies the temporary archive before it replaces the destination. Entry order, compression and dates stay; the output passes `zipfile.testzip()`; applying the same `PatchSet` twice gives the same summary and the same bytes. `layer_config_ranges.xml` ids are build-order indexes.
   Test: `tests/test_edits.py::test_save_rejects_undeclared_entry_change`, `test_undeclared_deletion_raises`, `test_edit_applied_twice_is_idempotent`.
12. **Verify after export.** `Pipeline.verify()` compares bed type, process name, filament and plate and object counts, start/end G-code length and every process override against the written file.
13. **Explicit failure.** Missing preset, binary, STL, or a crashed/timed-out CLI raises a `BambuError` subclass or yields a `RunResult` with a non-zero code and a meaning string; no `except` returns `None` silently. The documented silent fallbacks: a malformed optional numeric setting takes Studio's default, with a comment at the parse (`layout._int`, `tower._f` raises instead for the tower inputs); an unreadable Studio log, a missing Studio version, an unreadable mesh outline and a malformed filament or nozzle map are never silent (a WARN line or a log warning naming the path). `ruff check --select BLE001,E722` is clean except seven documented `# noqa: BLE001`: two in the facade's doctor (the config and machine sections: one section's failure must not hide the others), two in the MQTT teardown (`loop_stop` and `disconnect` after a read), the injectable port probe in `ArpProbe` (a closed port is False; any other exception is logged and counted closed), the caller's `on_step` progress callback (logged, never fails the read), and the printer read's worker thread (`BaseException` caught to re-raise it in the caller's thread). The CAD gates add none: the optional extra's import raises `GeomMissing` from the `ImportError`, and a manifold3d refusal becomes a typed `GeomError` and a `clash.boolean_failed` FAIL finding. The topology modules add none: `topo.require` raises `TopoDependencyError` from the `ImportError`, a singular stiffness matrix raises `TopoError`, and `peak_rss_mb` is null (documented) where the `resource` module does not exist.

## Safety

14. **Secrets.** The LAN access code enters only through `conf.access_code()` and `printer.StudioCredentials.code()` (Studio's config), `vault.Vault.get()` (the credentials file) and `cli.read_access_code()` (a one-shot flag or the `login` prompt), and each registers it with `conf.remember_secret`. It is held only in `repr=False` fields (`MqttReader.access_code`, `OneShotCredentials.value`, `Resolved.code`, `Bambu.printer_code`) and in `conf._RUNTIME_SECRETS`, written only to `credentials.json` (mode 0600) by `vault.FileVault`, never logged or printed, and never passed on a command line. Test: every test that `rg -l "SENTINEL-CODE" tests` lists passes (`test_cli.py` covers `printer login`, `list`, `forget`, `discover`, `status` and `main`'s error path; the other files cover the reads, the TLS path, Studio's config, the profile store, the credentials file and the calibration file); each asserts the sentinel code is absent from stdout, stderr and the files it checks.
15. **Read-only printer.** The only MQTT publish is the `pushall` request. Fail if `rg -n "publish\(" shambu` shows another topic or payload, or any code path sends `project_file`, `pause`, `stop`, `resume`, `print`.
16. **No GUI keystrokes.** No `osascript ... keystroke`. Opening a project uses `open -a BambuStudio`.

## Quality

17. **Types and lint.** `ruff check .` clean with the `pyproject.toml` rule set; `mypy shambu` reports no errors in `spec.py`, `assemble.py`, `layout.py`, `patches.py`, `presets.py`, `printability.py`, `meshgeom.py`, `findings.py`, `integrity.py`, `cad/`, `topo/` (the `topo` CI job runs mypy with the extras installed).
18. **Tests offline by default.** `python3 -m pytest -q` passes without the Studio binary, the network or paho (integration tests skip unless `SHAMBU_INTEGRATION=1`). The main CI job installs no extra; `tests/test_cad_geom.py` skips there and runs in the `geom` job, which installs the geom extra; `tests/test_topo_solver.py` and `tests/test_topo_trace.py` skip there and run in the `topo` job, which installs the topo extras.
19. **CLI UX.** Every subcommand supports `--json` with exactly one JSON document on stdout and logs on stderr; exit codes 0 ok, 1 a check failed or a patch was refused, 2 usage, 3 environment error (a file that cannot be written included), 130 interrupted. The exceptions: `printer watch --json` prints JSON lines, one document per poll; an argparse error prints its usage text on stderr before any JSON (exit 2). `--help` works without paho. `shambu cad`: 0 gate pass, 1 fail, incomplete or stale (or an invalid spec), 2 usage, 3 environment (`GeomMissing` included); `--help` and every stdlib verb work without the geom extra (`tests/test_cad_cli.py::test_geom_not_imported_at_collection`). `shambu topo`: 0 ok (WARN and INFO allowed), 1 a spec error, a FAIL finding or a failed `validate`, 2 usage, 3 environment (`TopoDependencyError` included); `--help` and `topo check` work without an extra (`tests/test_topo_cli.py::test_numpy_not_imported_at_collection`).
20. **Docs.** Every module has a docstring that states what it handles and what it does not; `README.md` shows the three main flows (build a spec, patch a file, read the printer); the SKILL.md recipe points at `shambu`, not at hand-assembled flags.
21. **Findings name their evidence.** Every `findings.Finding` carries one of `measured`, `observed`, `external`, `heuristic`; only `measured` can be FAIL, and `observed`, `external` and `heuristic` are WARN at most (the constructor refuses more). `printability` has no overall score and always lists what it did not check; integrity findings never change an exit code.
   Test: `tests/test_printability.py::test_every_finding_has_evidence`, `::test_only_measured_evidence_can_fail`, `::test_no_overall_score_anywhere`, `tests/test_integrity.py::test_external_evidence_never_fails`, `::test_verify_lines_never_fail`.
22. **CAD gates judge files.** `shambu cad` reads exported files and the records `stamp` writes; it never starts or imports a CAD program, and a rule that could not evaluate a part is INCOMPLETE (a `cad.incomplete.*` FAIL), never a pass. Parts are picked by selectors, never by file name; a distance is never `inf`; `--promote` writes only new files.
   Test: `tests/test_cad_spec.py::test_empty_selector_incomplete`, `::test_fixed_part_by_role_not_name`, `tests/test_cad_provenance.py::test_stale_stl_sha`, `::test_promote_never_overwrites`, `tests/test_cad_cli.py::test_cad_package_stays_off_cad_programs`.
23. **Topology results are maps, not proofs.** Every `shambu topo solve`, `validate` and `trace` result carries `topo.map_not_proof`, `topo.stiffness_not_strength` and `topo.pitch_dependent` and the not-checked list (strength, buckling, anisotropy, joints, the redesigned part, printability). Only `topo.equilibrium`, `topo.passive_not_one`, `topo.clearance`, `topo.under_constrained` and `topo.non_finite` are FAIL; every document is strict JSON (a NaN or an infinity becomes null and a `topo.non_finite` FAIL); no text says a part is strong, safe or certified. The optimiser reports progress through a listener and returns data; nothing under `src/shambu/topo` prints.
   Test: `tests/test_topo_cli.py::test_twenty_seven_codes_and_five_fails`, `::test_seal_turns_a_nan_into_null_and_a_fail`, `::test_a_report_always_lists_what_it_did_not_check`, `::test_topo_package_never_prints`, `tests/test_topo_solver.py::test_equilibrium_guard_fails_the_run`, `::test_passive_guard_fails_the_run`, `tests/test_topo_trace.py::test_clearance_at_the_rule_is_a_fail`.
